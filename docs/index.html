How it works

Spotify plays in the Spotify desktop app you already have. That app is a Chromium page signed in to your account. Maestro starts it with a local debugging port and drives it through the Chrome DevTools Protocol, using the same player and search Spotify's own interface uses. That is why no developer API keys or Premium subscription are involved. Spotify stays hidden unless you open it yourself.

YouTube and SoundCloud play in their own embedded players inside Maestro's window. Search uses their public web clients, so there are no API keys here either.

Handoffs. When a song ends, Maestro starts the next one on whichever service it comes from. Spotify songs hand off about 0.3 seconds early, so Spotify's own autoplay never interrupts your queue. If you skip inside Spotify or with media keys, Maestro follows along.

Security. While Spotify runs with the debugging port, other programs on this computer can control the Spotify app through it. The port accepts only local connections, and restarting Spotify normally removes it. More details are in the README.

Frequently asked questions

What is Maestro?

Maestro is a Windows music player that brings Spotify, YouTube, and SoundCloud into one app. You search all three at once, build playlists and a queue that mix them, and Maestro switches between services automatically as songs end.

Do I need API keys or a developer account?

No. Maestro needs no Spotify developer app, no YouTube Data API key, and no SoundCloud API registration. Install it, open it, and search.

Do I need Spotify Premium?

No. Spotify songs play through your own Spotify desktop app, signed in to your account, so a free account works. Use Spotify's installer from spotify.com; the Microsoft Store version isn't supported.

How does Maestro play Spotify without API keys?

Maestro starts your installed Spotify desktop app with its local debugging port enabled and talks to it through the Chrome DevTools Protocol. It uses the same player and search the Spotify app itself uses, so no developer credentials are involved. The port only accepts connections from your own computer.

Can I mix Spotify, YouTube, and SoundCloud in one playlist or queue?

Yes. Add tracks from any of the three services to one queue or one Maestro playlist. When a track ends, Maestro starts the next one on whichever service it comes from.

How does Maestro handle volume differences between services?

One slider controls all three services, and Maestro measures each YouTube and SoundCloud track and adjusts it to match Spotify's level, so you don't have to touch the volume between songs.

Is Maestro ad-free?

Yes. Maestro shows no ads of its own. Spotify plays through your Spotify desktop app, so patch it with SpotX and Spotify's ads are gone too. YouTube videos that Maestro plays from youtube.com have their ads removed before they load.

Is Maestro free? Is it open source?

Maestro is free for personal use and its full source code is on GitHub. It is source-available under the Business Source License 1.1 rather than an OSI open-source license: production use by a business needs a separate license, and each release converts to GPL-2.0-or-later four years after it is published.

What platforms does Maestro support?

Windows 10 and Windows 11 (64-bit). macOS and Linux are not supported yet.
